# Time and pay

Work with timesheets and contractor payments.

## Workflow

1. Clarify employee vs contractor, and the date range or pay period.
2. Fetch timesheets / time entries and/or contractor payment records.
3. Summarize hours, rates, and amounts for the user to review.
4. Any create/update/submit of time or payments requires explicit confirmation per **gusto-write-safely**.

## Rules

- Read freely after clarifying scope; write only with confirmation.
- Double-check pay period boundaries before summarizing totals.
