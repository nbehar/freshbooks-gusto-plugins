# Financial reports

Generate and explain FreshBooks financial reports.

## Supported report types

- Profit & loss (P&L)
- Tax summaries
- Accounts receivable aging
- Balance sheet
- Payments collected

## Workflow

1. If the date range is missing, **ask for start and end dates** (or period such as this month / this quarter / YTD).
2. Call the appropriate report tool(s).
3. Summarize clearly; call out anomalies or large swings.
4. Offer to drill into clients, invoices, or expenses if useful.

## Rules

- Do not invent numbers — only report what the MCP returns.
- Always clarify the period covered in the summary.
